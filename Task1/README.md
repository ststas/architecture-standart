# Task1

В директории находятся артефакты по текущей архитектуре банка «Стандарт».

## Артефакты

- [IT-landscape-map.drawio](./IT-landscape-map.drawio) — карта текущего IT-ландшафта.
- [IT-landscape-map.drawio.png](./IT-landscape-map.drawio.png) — экспорт карты текущего IT-ландшафта.
- [app-integration-diagram.drawio](./app-integration-diagram.drawio) — схема интеграции приложений с участниками процессов.
- [app-integration-diagram.drawio.png](./app-integration-diagram.drawio.png) — экспорт схемы интеграции приложений.

## Обозначения

- Синий блок — внутренняя разработка банка.
- Фиолетовый блок — решение поставщика в контуре банка.
- Зелёный блок — внешняя система вне контура банка.
- Серый овал — действующее лицо / участник процесса.
- Серая сплошная линия — системная интеграция или работа участника в системе.
- Красный пунктир — ручной процесс: письмо, Excel/XLS, скрипты.
- Синий пунктир — путь клиента.
- Светло-серый пунктир — путь клиента, который не фиксируется в системах.

## Основные допущения

- Ежедневный Excel/XLS с базовыми депозитными ставками передаётся из кредитного бэк-офиса в депозитный бэк-офис.
- Данные кредитного риска по конкретному клиенту передаются кредитным бэк-офисом по запросу депозитного бэк-офиса для расчёта спецставки.
- Ставка или спецставка передаётся из депозитного бэк-офиса во фронт-офис по запросу клиента.
